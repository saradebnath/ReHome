# ReHome
AI generated summary of plan: A user enters “desk lamp,” optionally adds a photo, selects category and condition, and chooses whether the item is reusable or broken. The app applies simple rules to recommend donation, give-away, e-waste, textile recovery, or recycling options, then sorts a verified Eastside directory by distance.
Primary user: a household that wants a fast, responsible alternative to throwing an item away.
Core promise: from item to suitable nearby options in under one minute.
Technical story: transparent matching rules + location sorting + a curated local dataset.
Privacy posture: photos remain in the browser for preview in the MVP; no upload server is needed.
